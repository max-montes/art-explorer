Art Explorer: Azure resources and costs

Resource What it does Cost
Container App Serves the website and API and runs local Jina/SigLIP query inference. Starts on incoming traffic. Estimated cached cold visit: 20-60 seconds to first results, potentially longer. First-ever model downloads can take several minutes. These are planning estimates, not Azure measurements. Cached Jina initialization on the development Mac measured 2.94 seconds, versus 0.13 seconds for the next query. Azure scheduling, image pulls and model-file reads add time. The wake-up UI appears only after the frontend loads. Our scale-to-zero setup: $0 compute while asleep. At 2 vCPUs and 4 GiB, actively running compute costs about $0.22/hour before free grants. For example, 10 active hours per month cost about $2.16 before grants, plus any billable idle time before scaling down. The roughly $47/month idle figure applies only if one replica is kept running all month instead of scaling to zero. It is not a minimum charge for our setup. Subscription free grants can reduce compute costs.
Container Apps environment Provides networking and runtime infrastructure for the app. No separate base compute fee for our basic Consumption setup. Dedicated profiles and optional networking features can add fees.
PostgreSQL B1ms Stores artwork metadata and embeddings and ranks image vectors. Provides 1 vCore, 2 GiB RAM and 32 GiB provisioned storage. Approximately $16/month: $12.41 compute plus $3.68 storage. No automatic scale-to-zero; kept running while the app sleeps. Manual stopping suspends compute charges, but searches cannot automatically wake the database. Storage charges continue. No high availability or replicas. Backups within the included allowance incur no additional storage charge.
Azure Files and storage account Keeps downloaded model files across container restarts, avoiding repeated model downloads. Does not scale to zero. Stored-data charges continue while the app sleeps; transactions are charged when files are accessed. Depends on actual stored bytes and file activity.
Container Registry, Basic Stores the application image used to start containers. Approximately $5/month even while the app sleeps, plus applicable extra storage and transfer charges.
Log Analytics Collects application logs for troubleshooting. Usage-based. Little or no new ingestion while asleep. Billable ingestion and retention depend on usage; the template sets a 0.1 GB daily ingestion cap and 30-day retention.
Managed identity and role assignment Lets the app pull its image without registry passwords. No separate charge.
Resource group Organizes Art Explorer's Azure resources. Free.
Total estimate West US 3 public USD pay-as-you-go estimates, checked 2026-10-08. Monthly running estimates use 730 hours. Our scale-to-zero setup: about $21/month fixed baseline, plus model storage, logging and app running time. At 10 active hours per month, baseline plus active app compute is about $23 before free grants and those extras. Optional always-on comparison, not our default: roughly $65-$85/month at light traffic with one warm replica, or about $175/month if continuously active. Your $150/month Azure credit and Container Apps free grants are shared with Art Guide and other subscription resources. Estimates are not spending caps or guaranteed bills.
